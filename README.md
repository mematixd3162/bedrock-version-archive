---

## 🛠️ How to Install Old Versions

Follow these simple steps to install any version:

1. **Backup Your Worlds (Optional):** Save your `minecraftWorlds` folder just in case.
2. **Uninstall Current Version:** Go to `Windows Settings > Apps > Installed Apps` and uninstall your existing Minecraft.
3. **Enable Developer Mode:** Go to `Windows Settings > Privacy & Security > For Developers` and toggle **Developer Mode** ON.
4. **Download & Install:**
   - Click on your desired version from the index to download the `.appx` file.
   - Double-click the downloaded `.appx` file and click **Install / Update**.
5. **Disable Auto-Updates (Important):**
   - Open **Microsoft Store** -> Click your Profile Icon -> **Settings**.
   - Turn **OFF** "App Updates" so Windows doesn't automatically overwrite your version.
